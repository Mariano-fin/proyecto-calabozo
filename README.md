# Dungeon Helper v0.1 

*Proyecto para ayudar con la organización y navegación de calabozos para juegos de mesa y rol*

**Link de repo:** https://github.com/Mariano-fin/proyecto-calabozo

- Landing y layout básico de mapa
- Diseño responsive

## Características por implementar

- Exportación de datos en JSON
- Guardado de datos en localStorage
- Carga de archivos de manera segura
- Conversión de archivos PNG y PDF a JPG
- Modales editables y borrables según ícono
- Barra lateral de íconos
- Mejoramiento de nav
    


## CÓMO UTILIZAR

1. El primer paso es subir un archivo válido usando el botón que indica "Subir archivo". Es posible subir archivos .jpg, .png o .pdf (que serán convertidos a .jpg), con un peso no superior a 10mb
2. Con el mapa cargado, se habilitará una barra lateral a la izquierda, con distintos íconos. Estos íconos se pueden arrastrar sobre el mapa, donde quedarán "fijos". 
3. Al hacer click en ellos, se desplegará una Modal personalizada según el ícono utilizado. Dicha Modal puede ser completada por el usuario, editada y eliminada.
